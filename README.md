# SMIU Events Portal

A responsive front-end website concept for the SMIU Student Affairs Office. Students can browse sample campus events, read event details, explore student societies and complete demonstration registration/contact forms.

> **Important:** Event names, dates, venues, office contact details, membership counts and staff information in this project are sample content for an academic demonstration. Confirm all real information with SMIU before public use. Forms are front-end demonstrations only and do not send or store personal data.

## Technologies

- HTML5 and semantic page structure
- CSS3 with custom theme variables and responsive rules
- Bootstrap 5.3.3 CSS and JavaScript bundle through jsDelivr CDN
- Bootstrap Icons 1.11.3
- Original SVG illustrations stored in `images/`
- Vanilla JavaScript for demonstration form feedback

## How to run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Start the pages using the VS Code Live Server extension, or open `index.html` in a browser.
4. Keep an internet connection available because Bootstrap and Bootstrap Icons are loaded from CDNs.
5. Navigate using the shared navbar. No server, database or build step is required for this front-end demonstration.
